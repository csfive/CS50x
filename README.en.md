## Build & Check

Compile locally on macOS with Homebrew `libcs50`, and verify with `style50` / `check50`:

```bash
clang -Wall -Wextra -I/opt/homebrew/include -L/opt/homebrew/lib -lcs50 -lm hello.c -o hello
style50 hello.c
check50 cs50/problems/2026/x/me
```
